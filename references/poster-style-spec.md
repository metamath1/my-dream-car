# Poster style specification

This text specification is a fallback for environments where the bundled poster-style reference image is unavailable.

## Canvas and composition

- Vertical poster, approximately 9:16.
- Bright white to very light gray studio background.
- Small, widely spaced uppercase model/manufacturer line near the top.
- One enormous pale-gray model-name word behind the vehicle.
- Hero vehicle centered in the middle to lower-middle region, usually in front three-quarter view.
- Vehicle should occupy a consistent visual scale across a paired poster set.
- Subtle glossy floor reflection and restrained curved tire-track accents.

## Lower information area

- Large bold model title on a fixed baseline near the lower section.
- One short centered description line or two compact lines below the title.
- Thin horizontal rule below the description.
- Four equally spaced specification cells along the bottom.
- Thin vertical dividers between the four cells.
- Each cell uses a small uppercase label with a larger value below it.

## Visual tone

- Premium automotive brochure aesthetic.
- Minimal, clean, restrained, high-key studio lighting.
- Monochrome typography with generous whitespace.
- No decorative element should distort or obscure the exact vehicle geometry.

## Series consistency

When two or more posters are requested, the first accepted poster becomes the layout anchor. Keep the canvas size, top line, background word, hero zone, title baseline, description position, horizontal rule, and bottom specification strip aligned across the entire set.
