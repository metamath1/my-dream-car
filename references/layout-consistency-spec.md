# Layout consistency spec

Use this file when the user requests a paired or multi-poster set.

## Goal

Make the posters look like one coherent series. The car may change, but the poster template should remain visually locked.

## Fixed template expectations

- identical canvas aspect ratio and export size across the set
- the same outer margins and whitespace balance
- the same top small-text position
- the same pale oversized background word scale and placement logic
- the same title width region and baseline
- the same description block position and spacing below the title
- the same bottom horizontal rule
- the same four-cell specification strip width, divider spacing, and vertical position

## Car placement rule

The car should be placed within the same hero zone in every poster.
The visual scale may be adjusted slightly to fit the model, but the vehicle should occupy a similar proportion of the poster and sit on the same ground/reflection system.

## Workflow rule

For a pair or set, generate the first final poster and then use it as the layout anchor for the remaining posters. Do not generate all final posters independently from scratch if consistent layout is required.

## Validation checklist

- same export size
- same aspect ratio
- same main text alignment system
- same bottom spec strip position
- same whitespace rhythm
- cars framed consistently
